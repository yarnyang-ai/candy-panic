# Candy Rush

GitHub Pagesで動く、30秒のお菓子集めゲーム。ユーザー指定は男の子と操作キャラクターが16×16、ばらまくお菓子が1ドット、青+1・オレンジ+5・赤+10・グレー−1、スタート→カウントダウン→30秒→シェア可能な結果。

## Approach
Canvas 2D + HTML/CSS + JavaScript modulesを採用する。ゲームエンジン案は依存とビルドが増え、この規模には不要。GitHub Pagesで公開するためサーバー機能も不要。外部CDN・画像・フォントには依存しない。

## Design decisions
制作側の判断：横視点の夕暮れの森、浮島、ピクセル単位の粒子、左右移動と2段ジャンプ。論理解像度480×270、キャラ16×16、お菓子1×1。グレーはユーザーの追加指定で2×2のSTONEに変更し、移動速度は通常の半分、地面・足場への接触で消滅する。残り5秒は1回のばらまき量を6個から12個に増やす。見た目の拡大は最近傍補間。Noitaの雰囲気を参考にオリジナルの絵をCanvasで描き、地形破壊は含めない。

画面外にゲーム名・自己ベスト・色別の得点・操作説明。飾りのフレーバーテキストは削除し、ルールと操作に必要な文章に絞る。ゲーム領域内にスタートと結果のオーバーレイ。キーボードとタッチに対応。画面を離れた場合は一時停止し、公平なプレイ時間を保持する。

結果は合計と色別内訳・自己ベストを表示。OSの共有、Xの投稿作成、テキストコピーを提供する。投稿送信はユーザー自身が行う。自己ベストのみローカル保存。公開ランキングやサーバー保存は今回の範囲外。

## Verification
Node標準テストで時間境界、色別得点、二重回収防止、移動・ジャンプ・着地・境界とリセットを確認。ブラウザーで実際の開始→カウントダウン→操作→結果、再挑戦、モバイル表示と共有の操作を確認する。
